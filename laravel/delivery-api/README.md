<h1>Сервис управления бронью слотов</h1>

<p>
Мы проектируем сервис, который управляет бронью слотов (складские окна, доставка или время приема клиентов). Каждый слот имеет ограниченную вместимость, пользователи могут создавать временные холды, а затем подтверждать их. Обеспечивается корректная работа под нагрузкой: горячий кеш, транзакции, защита от оверсела.
</p>

<h2>Запуск</h2>
<p>Запуск проекта может быть произведен в среде с установленным web-сервером (Apache, Nginx), PHP 8.2+ и MySQL 8+. Для реализации кэша должен быть установлен и запущен Redis</p>
<p>В среде должен быть установлен composer и git, настроены виртуальные хосты</p>

<h2>Этапы запуска</h2>
<ol>
	<li>Клонируем код в нужную директорию на сервере (должен быть настроен виртуальный хост). git clone</li>
	<li>Накатываем laravel. composer install</li>
	<li>Настраиваем laravel. (.env)<li>
	<li>Запускаем миграции. php artisan migrate</li>
</ol>

<h2>Примеры curl запросов</h2>

<p>Получить слоты</br>
<code>curl "https://some-host.com/api/slots/availability"</code>
</p>

<p>Создать холд в слоте id=1 с ключем идемподентности key001</br>
<code>>curl -d '{"status":"held"}' -X POST --header "Idempotency-Key: key001" "https://some-host.com/api/slots/1/hold"</code>
</p>

<p>Подтвердить холд с id=1</br>
<code>curl -X POST "https://some-host.com/api/holds/1/confirm"</code>
</p>

<p>Отменить холд с id=1</br>
<code>>curl -X DELETE "https://some-host.com/api/holds/1</code>
</p>
