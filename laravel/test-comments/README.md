# Comments API

Простое REST API для системы комментариев к контенту  
Стек: **PHP 8.2+, Laravel 11+, MySQL 8+**  
Шаблоны и фронтенд не используются — только API.

---

## Возможности

- Сущности:
  - Новость (News)
  - Видео пост (VideoPost)
  - Пользователь (User)
  - Комментарий (Comment)
- Комментарии можно оставлять:
  - к новости
  - к видео посту
  - к другому комментарию (любая глубина вложенности)
- CRUD для новостей и видео постов
- CRUD для комментариев от лица пользователя
- Cursor-based пагинация комментариев
- Поддержка вложенных ответов

---

## Архитектура

### Модель комментариев

- Комментарий привязывается к контенту через полиморфную связь:
  - `commentable_type`
  - `commentable_id`
- Вложенность через:
  - `parent_id` → ссылка на другой комментарий
- Ответ на комментарий наследует `commentable_type` и `commentable_id` родителя

### Что покрывают тесты

#### Новости (News)
- `GET /api/news` — получение списка новостей
- `POST /api/news` — создание новости
- `GET /api/news/{id}` — получение новости с комментариями
- `PUT /api/news/{id}` — обновление новости
- `DELETE /api/news/{id}` — удаление новости

#### Видео посты (VideoPost)
- `GET /api/video-posts` — список видео постов
- `POST /api/video-posts` — создание видео поста
- `GET /api/video-posts/{id}` — получение видео поста с комментариями
- `PUT /api/video-posts/{id}` — обновление видео поста
- `DELETE /api/video-posts/{id}` — удаление видео поста

#### Комментарии (Comments)
- Создание комментариев:
  - к новости
  - к видео посту
  - ответ на комментарий
- Получение комментариев:
  - корневые к новости
  - корневые к видео посту
  - ответы к комментарию
- Обновление комментария:
  - разрешено только автору
  - проверка 403 для другого пользователя
- Удаление комментария:
  - разрешено только автору
- Валидация:
  - указана ровно одна цель (`news_id` / `video_post_id` / `parent_comment_id`)

#### Пагинация
- Проверяется cursor-based пагинация:
  - первая страница
  - переход по `next_cursor`
  - отсутствие пересечений элементов между страницами
