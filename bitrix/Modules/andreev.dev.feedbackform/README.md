<p>Пример создания модуля обратной связи для Битрикс</p>
<p>Функционал:</p>
<ul>
    <li>Установка (Регистрация модуля, создание хранилища, копирование компонента и шаблона)</li>
    <li>Удаление (удаление хранилища и всех записей, удаление компонента и шаблона)</li>
    <li>Хранение данных формы в Highload блоке</li>
    <li>Проверка заполнения формы</li>
    <li>Компонент и шаблон для формы (устанавливается вместе с модулем)</li>
</ul>

<p>Модуль готов к установке</p>

```php
//Пример вставки шаблона компонента на страницу
$APPLICATION->IncludeComponent(
    "andreev.dev:feedbackform",
    ".default",
    [],
    false
);
```
