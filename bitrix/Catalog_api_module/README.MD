<h1>Модуль взаимодействия с каталогом посредством REST API</h1>
<p>Модуль для реализации некоторых REST-контроллеров интернет-магазина, использующий новую модель роутинга.</p>
<p>1. Методы REST API</p>
<ul>
<li>Вывод списка категорий каталога &laquo;Одежда&nbsp;</li>
<li>Вывод списка товаров каталога &ldquo;Одежда&rdquo; в заданной категории</li>
<li>Вывод детальной информации о товаре</li>
</ul>
<p>Результат представлен в виде файла спецификации OpenAPI в корне репозитория (openapi.yaml)</p>
<p>2. Роутинг для спроектированного API находится в файле /local/routes/api.php</p>
<p>3. Модуль находится в папке /local/modules/catalog.api</p>
<p>4. Разработан консольный скрипт реализующий выгрузку товаров в формате Excel на заданный e-mail</p>
<p><strong>Прочее:</strong></p>
<ol>
<li>Пример настройки web-сервера находится в корне сайта</li>
<li>Требуется установить зависимости из файла /loca/php_interface/composer.json</li>
<li>В случае, если модуль не устанавливается из админки запустить напрямую из браузера /local/install_catalog_api.php</li>
</ol>
